Privatumo politika

Atnaujinta 2026-10-28

Ši politika aprašo nepriklausomą, privačiai GitHub paskyros ArturasBud savininko valdomą Hermes integraciją. Ji nėra visos Hermes Agent programinės įrangos ar kitų jos diegimų privatumo politika.

1. Kokie duomenys gali būti pasiekiami?

Prieiga priklauso nuo Google sutikimo ekrane suteiktų leidimų ir konkrečios savininko užduoties. Tai gali būti Gmail laiškai, priedai ir metaduomenys; Calendar įvykiai; Drive failai ir jų metaduomenys; Docs dokumentai; Sheets lentelės; Contacts kontaktai. Verslo užduotims gali būti pasiekiamos autorizuotų Analytics, Ads, Search Console, Tag Manager ir svetainių nuosavybės paslaugų ataskaitos bei konfigūracija.

Kai suteiktas atitinkamas rašymo leidimas, savininko nurodymu gali būti siunčiami laiškai, keičiami dokumentai, kalendoriaus įvykiai ar paslaugų nustatymai. Tai nėra vien skaitymo integracija; konkretūs išoriniai veiksmai reikalauja savininko nurodymo ir patvirtinimo.

2. Kam naudojami duomenys?

Duomenys naudojami savininko pasirinktoms funkcijoms: paieškai, informacijos apibendrinimui, dokumentų rengimui, planavimui, ataskaitoms ir aiškiai patvirtintiems pakeitimams. Google prieiga nėra leidimas viešinti savininko ar jo klientų turinį. Google API duomenys neskirti pardavimui, reklamos auditorijų kūrimui ar bendros paskirties DI modelių mokymui.

3. DI paslaugos ir perdavimas

Hermes gali naudoti savininko pasirinktą išorinį DI modelio teikėją. Užduoties tekstas ir atsakymui reikalingos Google duomenų ištraukos gali būti perduodami šiam teikėjui apdoroti. Todėl šios integracijos negalima laikyti vien tik vietiniu, be išorinio apdorojimo veikiančiu įrankiu.

Konkretaus teikėjo duomenų saugojimo ir naudojimo sąlygos bei savininko nustatymai turi būti įvertinti prieš perduodant duomenis. Ši svetainė neteigia, kad kiekvienam galimam DI teikėjui automatiškai taikomas vienodas duomenų saugojimo ar nenaudojimo mokymui režimas. Perduodant Google API duomenis būtina laikytis Google API Services User Data Policy, įskaitant taikomus Limited Use apribojimus. Integracija pati nevykdo DI modelių mokymo.

4. Saugojimas ir saugumas

Google prieigos duomenys saugomi savininko valdomoje aplinkoje. Jie nėra skelbiami šioje svetainėje ar jos viešoje repozitorijoje. Darbo ištraukos gali likti vietinėse užduočių bylose, ataskaitose, pokalbių istorijoje ir savininko atsarginėse kopijose. Vieno automatinio visų šių duomenų ištrynimo termino nėra; saugojimą ir pašalinimą valdo savininkas.

Asmeniniai ir verslo duomenys turi būti tvarkomi pagal užduoties paskirtį. Viešai skelbiami tik savininko patvirtinti dokumentai ar informacija. Techninės saugumo priemonės mažina riziką, bet nėra absoliutaus saugumo garantija.

5. Prieigos atšaukimas ir duomenų pašalinimas

Google leidimą galima atšaukti Google paskyros trečiųjų šalių ryšių nustatymuose. Tai sustabdo tolesnį API naudojimą pagal atšauktą leidimą, tačiau savaime neištrina jau atsisiųstų failų, ataskaitų, pokalbių ar jų atsarginių kopijų. Šiuos duomenis savininkas pašalina atskirai iš savo darbo aplinkos ir, kai taikoma, iš išorinio paslaugos teikėjo saugyklos.

6. Šios svetainės lankytojai

Šie puslapiai yra statiniai. Juose nėra Google prisijungimo, duomenų įvedimo formų, mūsų įdiegtos lankytojų analitikos ar slapukų. Svetainę talpina GitHub Pages; GitHub gali tvarkyti techninius užklausų duomenis pagal savo privatumo taisykles. Viešas šių puslapių prieinamumas nesuteikia prieigos prie savininko Google paskyros.

7. Kontaktas ir pakeitimai

Integracijos valdytojas – GitHub paskyros ArturasBud savininkas. Techniniams klausimams skirta projekto problemų skiltis; joje negalima skelbti prieigos raktų, privačių laiškų ar dokumentų. Pasikeitus duomenų naudojimui ši politika atnaujinama, o naujoms Google prieigos apimtims ar naudojimo tikslams reikia atitinkamo savininko sutikimo.
