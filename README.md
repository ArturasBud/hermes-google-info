# Hermes Google integration information

Public informational pages for the independently operated private Hermes integration of GitHub user ArturasBud.

- `index.html` — application purpose, operator and link to privacy information.
- `privacy.html` — Google data access/use, external AI processing, storage, revocation and site-hosting disclosures.
- `styles.css` — local stylesheet, no external assets.
- `.nojekyll` — publish these static files unchanged through GitHub Pages.
- `robots.txt` — permit retrieval; HTML pages request no indexing through a robots meta tag.

This repository is intentionally public. It contains no assistant application source, credentials, OAuth client configuration, tokens, user correspondence, client records or private project files. It is not an official Google or Nous Research service and is not a publicly available login application.

Google Cloud publishing status and OAuth access are configured separately. Publishing these pages does not itself prove Google verification or durable authorization.
